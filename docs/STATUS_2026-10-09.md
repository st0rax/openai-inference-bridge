# Project status — 2026-10-09

## Current state

The repository has a verified Rust scaffold, cross-platform CI, and the initial safe-configuration layer. This is still a foundation, not a usable inference service: no HTTP API or browser-chat runtime is implemented.

- Repository bootstrap and planning documents are present.
- Source-level audit of upstream `st0rax/webagent-rs` is complete and documented.
- The earlier recommendation to use WebAgent's public API bridge has been superseded. The project implements its own OpenAI-compatible API and internal Brain interface.
- Individual source reuse evaluation for the initial browser-text path is complete. No WebAgent code or crate dependency is approved for reuse.
- The project-owned BrainBackend contract, Brain registry/model-ID policy, per-Brain capability policy, normalized request/event policy, and conversation-state policy are documented.
- Rust scaffold and CI are implemented. GitHub Actions run [37872755005](https://github.com/st0rax/openai-inference-bridge/actions/runs/37872755005) passed formatting, Clippy, and tests on Ubuntu and Windows.
- Safe configuration is implemented in `src/config.rs`: loopback default `127.0.0.1:8788`, required strong `OIB_API_TOKEN`, explicit remote-bind opt-in, platform-specific data directories, token redaction, and validated per-Brain profile paths.
- Configuration and secret-handling policy is documented in [CONFIGURATION.md](CONFIGURATION.md) and [CONFIGURATION_AND_SECRETS.md](CONFIGURATION_AND_SECRETS.md).

## Important unverified or unimplemented items

- The current CI proves formatting, Clippy, and unit tests for the existing scaffold/configuration only; it does not prove a live API or browser turn.
- No HTTP server, request authentication, `/v1/models`, or `/v1/chat/completions` implementation exists yet.
- No project-owned WebView/browser runtime has been built or tested.
- No live browser-chat turn or OpenAI-compatible client integration test has been run.
- Remote binding is only gated by configuration. TLS and a remote deployment security model are not implemented.
- No WebAgent dependency approach or copied source component is approved.

## Next steps

1. Implement the HTTP server and route structure on the project-owned interfaces.
2. Implement authentication and structured API errors before exposing inference routes.
3. Implement the Brain registry and `GET /v1/models` with strict canonical model IDs.
4. Implement non-streaming Chat Completions and request validation against the normalized types.
5. Build a minimal project-owned WebView runtime with a disposable, app-owned profile.
6. Implement one provider adapter and verify a complete live text turn.
7. Add streaming only after snapshot/delta behavior is demonstrated by live evidence.
8. Record exact commands, outputs, and limitations in `docs/proofs/`.
